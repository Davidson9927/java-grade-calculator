# java-grade-calculator
A simple Java application to calculate student grades.

Questions
1.GitHub Codespaces is a development environment in the cloud. You open VS Code in your web browser, and the code runs on a GitHub computer, not on your own computer.
2.A text editor only writes and changes text, like Notepad. An IDE has many tools in one program: it can compile, run and test the code, find errors and give suggestions while you write.
3.The javac command is the Java compiler. It reads your .java file and makes a .class file (bytecode). It also shows the errors in your code.
4.javac compiles the code, and java runs the program. First you use javac to make the .class file, and then you use java to start the program.
5.A GitHub repository is a folder online where you keep your project. It saves your files and the history of all the changes, so you can see old versions and work with other people.
6.The git push command sends your saved changes (commits) from your computer to the repository in GitHub. After that, your code is online.
7.A cloud-based development environment has many advantages. You do not need to install anything, you can work from any device with internet, and all students have the same tools. Your files are also saved online, so you do not lose them if your computer breaks. It is easy to share your project, and the work runs on a strong computer. The only disadvantage is that you need internet.
